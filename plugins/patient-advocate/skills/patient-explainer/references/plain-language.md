# Plain-language style guide

Aim for a **6th–8th grade reading level** without sounding childish. The reader is an intelligent adult who doesn't speak medicine.

## Sentences
- Short sentences: under 20 words on average. One idea per sentence.
- Active voice: "The doctor found…" rather than "It was noted that…"
- Talk to the reader: "you" and "your" (or "your mother" in caregiver mode).
- Put the main point first, then the detail.

## Words
- Use the everyday word. If the medical term matters (they'll hear it from the doctor, or see it on a portal), give the term once, then explain it: "**hypertension** (high blood pressure)". After that, use the plain word.
- Avoid abbreviations. Spell out and explain any that appear in the document: "eGFR — a number that shows how well your kidneys filter your blood."
- No hedging piles ("it may possibly suggest"). Say clearly what is known and what isn't.

### Common swaps

| Medical | Plain |
|---|---|
| benign | not cancer |
| malignant | cancer |
| lesion / mass / nodule | spot / lump / growth (match the size the report gives) |
| unremarkable / within normal limits | normal / looks healthy |
| acute | sudden / recent |
| chronic | long-lasting |
| bilateral | on both sides |
| edema | swelling from fluid |
| hypertension | high blood pressure |
| hyperlipidemia | high cholesterol |
| renal | kidney |
| hepatic | liver |
| cardiac | heart |
| pulmonary | lung |
| myocardial infarction | heart attack |
| cerebrovascular accident | stroke |
| prognosis | what to expect over time |
| etiology | cause |
| idiopathic | the cause isn't known |
| contraindicated | shouldn't be used because it could cause harm |
| PRN | only when you need it |
| NPO | nothing to eat or drink |
| follow up | come back / next appointment |
| clinical correlation recommended | your doctor needs to compare this with how you're feeling and other tests |
| incidental finding | something they noticed that wasn't what they were looking for |

## Numbers
- Give the patient's number, the normal range, and a plain verdict: "Your potassium was 5.6. Normal is 3.5 to 5.0, so it's high."
- Use "a little", "moderately", or "very" only when the report or reference range supports it.
- Compare to earlier results when the documents give them: "That's up from 1.2 in January."
- Round only if it doesn't change meaning, and keep the exact value nearby.

## Analogies
Use one when it genuinely helps understanding. Keep it accurate, not cute.
- Kidneys filter the blood "like a coffee filter"; eGFR "is how much they can filter each minute."
- A1c "is like an average of your blood sugar over the last 2–3 months."
- Ejection fraction "is how much blood the heart pushes out with each beat. A healthy heart pushes out a bit more than half."

## Tone
- Calm and steady. No exclamation points, no alarm words, no cheerleading.
- Never "just" or "only" about something serious.
- Acknowledge feelings briefly when the news is hard: "This is a lot to take in."

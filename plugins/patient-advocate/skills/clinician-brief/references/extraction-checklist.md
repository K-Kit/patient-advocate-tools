# Extraction checklist

Pull these from every document before writing. Note the source file and page for each item.

## Document metadata
- Document type (lab report, imaging report, discharge summary, H&P, consult, op note, path report, progress note, med list, referral)
- Date of service vs. date reported/signed (they often differ)
- Author, specialty, facility
- Ordering provider (labs/imaging)

## Patient context
- Age, sex
- Active problem list and PMH
- PSH with dates
- Pertinent FHx and SHx (tobacco pack-years, EtOH, substance use, occupation if relevant)
- Code status / advance directives if documented

## Medications
- Name, dose, route, frequency, indication if given
- Changes: started, stopped, dose changed, held, and the reason
- Discharge med list vs. admission med list vs. outpatient list (reconcile)
- Allergies and the reaction type

## Objective data
- Vitals (with date/time)
- Labs: value, units, reference range, abnormal flag, specimen date. Flag critical/panic values. Capture prior values for trending.
- Imaging: modality, body part, contrast, comparison study, **Impression** (verbatim), incidental findings and their follow-up recommendations (e.g. Fleischner, ACR incidentaloma guidance as stated in the report)
- Pathology: specimen, diagnosis, grade/stage, margins, receptor/biomarker status
- Procedures: what was done, findings, complications
- ECG/echo/PFT key measurements

## Assessment & plan
- Diagnoses as the authoring clinician stated them, including certainty language
- Recommendations, referrals, follow-up intervals
- Pending results at time of writing

## Cross-document checks (multiple documents)
- Trends in repeated labs or measurements
- Medication discrepancies between lists
- Results referenced but not present
- Recommended follow-ups with no evidence of completion
- Conflicting diagnoses or histories between authors
